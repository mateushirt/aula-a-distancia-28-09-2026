Aula à Distância (28/08/2026) - Meta Tags, Elementos e Atributos HTML

Meta tags utilizadas no head do HTML

  • Charset

    Indica a codificação, a forma que os caracteres da página serão convertidos e entendidos pelo navegador para que possam ser exibidos na tela. Existem diferentes tipos de codificação de caracteres. Alguns exemplos são o UTF-8, o ISO-8859-1 e o Windows-1252.

    Exemplo: No código <meta charset="UTF-8">, é definido que a codificação da página será em UTF-8.

  • Viewport

    Estabelece regras sobre como a viewport (a área visível do documento) deve ser dimensionada

    Exemplo: No código <meta name="viewport" content="width=device-width, initial-scale=1.0"> é especificado que o conteúdo visível ficará dentro da largura do dispositivo que está sendo utilizado e que a escala inicial será 100%.

  • Description

    Indica uma descrição ou resumo de uma página, que pode ser utilizado por mecanismos de pesquisa ao indexar uma página. No caso do Google, eles utilizam o conteúdo dessa tag caso compreendam que a descrição fornecida é mais precisa do que apenas uma busca no conteúdo da página.

    Exemplo: No código <meta name="description" content="Compilado de algumas meta tags do HTML."> é dado um resumo da página.

  • Author

    Indica qual é o nome do autor do documento.

    Exemplo: No código <meta name="author" content="Mateus"> é informado o autor do documento atual.

Meta tags Open Graph utilizadas no head do HTML

  • Open Graph: Title

    Define o que terá no campo de título quando a página é mencionada por outro aplicativo (como uma rede social).

    Exemplo: <meta property="og:title" content="Dinamarca se preparou para invasão dos EUA à Groenlândia | G1">

  • Open Graph: Description

    Define o que terá no campo de descrição quando a página é mencionada por outro aplicativo (como uma rede social).

    Exemplo: <meta property="og:description" content="Plano de contingência revelado por emissora pública mostra que reino levou a sério ameaças de Trump de anexar ilha do Ártico.">

  • Open Graph: Image

    Define o que terá no campo de imagem quando a página é mencionada por outro aplicativo (como uma rede social).

    Exemplo: <meta property="og:image" content="https://s04.video.glbimg.com/x720/992055.jpg">

  • Open Graph: URL

    Define o que terá no campo de URL quando a página é mencionada por outro aplicativo (como uma rede social). Ele indica qual é o link (URL) original da página.

    Exemplo: <meta property="og:url" content="https://g1.globo.com/mundo/blog/sandra-cohen/post/2026/03/20/dinamarca-enviou-explosivos-a-groenlandia-para-destruir-pistas-de-pouso-em-caso-de-invasao-dos-eua.ghtml">
