Aula à Distância (28/08/2026) - Meta Tags, Elementos e Atributos HTML

Página inicial Meta tags Formulários

Meta tags utilizadas no head do HTML

  • Charset

    Indica a codificação, a forma que os caracteres da página serão convertidos e entendidos pelo navegador para que possam ser exibidos na tela. Existem diferentes tipos de codificação de caracteres. Alguns exemplos são o UTF-8, o ISO-8859-1 e o Windows-1252.

    Exemplo: No código <meta charset="UTF-8">, é definido que a codificação da página será em UTF-8.

  • Viewport

    Estabelece regras sobre como a viewport (a área visível do documento) deve ser dimensionada

    Exemplo: No código <meta name="viewport" content="width=device-width, initial-scale=1.0"> é especificado que o conteúdo visível ficará dentro da largura do dispositivo que está sendo utilizado e que a escala inicial será 100%.

  • Description

    Indica uma descrição ou resumo de uma página, que pode ser utilizado por mecanismos de pesquisa ao indexar uma página. No caso do Google, eles utilizam o conteúdo dessa tag caso compreendam que a descrição fornecida é mais precisa do que apenas uma busca no conteúdo da página.

    Exemplo: No código <meta name="description" content="Compilado de algumas meta tags do HTML."> é dado um resumo da página.

  • Author

    Indica qual é o nome do autor do documento.

    Exemplo: No código <meta name="author" content="Mateus"> é informado o autor do documento atual.

Propriedades Open Graph utilizadas no head do HTML

  • Open Graph: Title

    Define o que terá no campo de título quando a página é mencionada por outro aplicativo (como uma rede social).

    Exemplo: <meta property="og:title" content="Dinamarca se preparou para invasão dos EUA à Groenlândia | G1">

  • Open Graph: Description

    Define o que terá no campo de descrição quando a página é mencionada por outro aplicativo (como uma rede social).

    Exemplo: <meta property="og:description" content="Plano de contingência revelado por emissora pública mostra que reino levou a sério ameaças de Trump de anexar ilha do Ártico.">

  • Open Graph: Image

    Define o que terá no campo de imagem quando a página é mencionada por outro aplicativo (como uma rede social).

    Exemplo: <meta property="og:image" content="https://s04.video.glbimg.com/x720/992055.jpg">

  • Open Graph: URL

    Define o que terá no campo de URL quando a página é mencionada por outro aplicativo (como uma rede social). Ele indica qual é o link (URL) original da página.

    Exemplo: <meta property="og:url" content="https://g1.globo.com/mundo/blog/sandra-cohen/post/2026/03/20/dinamarca-enviou-explosivos-a-groenlandia-para-destruir-pistas-de-pouso-em-caso-de-invasao-dos-eua.ghtml">

Outras meta tags utilizadas no head do HTML (+ ícone)

  • Referrer

    Controla o conteúdo do header HTTP com um HTTP referer anexado a qualquer pedido que o documento enviar. Seu conteúdo define o quanto da URL do documento é compartilhada.

    Exemplos:

    Considere a URL https://www.google.com/search?q=teste, sua "origem" será apenas https://www.google.com, sem as demais informações da URL.

    <meta name="referrer" content="origin"> apenas vai compartilhar a origem do documento.

    <meta name="referrer" content="no-referrer-when-downgrade"> apenas vai compartilhar a URL se a segurança se manter ou for melhorada (https → https, http → http, http → https). Nas demais situações, não envia nenhum HTTP referer.

    <meta name="referrer" content="origin-when-crossorigin"> envia a URL completa se a solicitação for da mesma origem, mas envia apenas a origem para os demais casos.

    <meta name="referrer" content="unsafe-URL"> envia a URL completa.

    <meta name="referrer" content="no-referrer"> não envia nenhum HTTP referer.

  • Content Security Policy

    Trata-se de uma camada de segurança a mais para o documento, facilitando a detecção e mitigação de determinados tipos de ataque. Ela estabelece uma listagem de origens de informação permitidas.

    Utiliza http-equiv ao invés de name pois simula cabeçalhos HTTP diretamente no código da página.

    Exemplo: O código <meta http-equiv="Content-Security-Policy" content="default-src 'self'; img-src https://*"> estabelece que todo conteúdo deve vir da mesma origem ("default-src 'self'") e que suas imagens devem vir de sites https ("img-src https://*").

  • Robots

    Define o comportamento que crawler indexers (rastreadores de indexação), também conhecidos como robots (robôs), podem ter dentro da página e se ela deve ou não ser indexada.

    Exemplos:

    <meta name="robots" content="index"> permite aos robôs indexar a página.

    <meta name="robots" content="noindex"> pede aos robôs para não indexar a página.

    <meta name="robots" content="follow"> permite aos robôs seguir os links que estão na página.

    <meta name="robots" content="nofollow"> pede aos robôs para não seguir os links da página.

    <meta name="robots" content="all"> equivale ao "index" e "follow" juntos.

    <meta name="robots" content="none"> equivale ao "noindex" e "nofollow" juntos.

    <meta name="robots" content="noarchive"> pede aos robôs para não armazenar a página em cache. Também pode ser substituído por "nocache".

    <meta name="robots" content="nosnippet"> previne que quaisquer descrições da página apareça em resultados de ferramentas de pesquisa.

    <meta name="robots" content="noimageindex"> pede para que o documento não seja referenciado quando uma imagem for indexada.

  • Keywords

    Define palavras-chave para mecanismos de pesquisa.

    Exemplo: <meta name="keywords" content="Tags HTML, meta, cabeçalho">

  • Theme Color

    Indica uma sugestão de cor para que os navegadores ou demais interfaces usem ao acessar a página. É ele quem faz o navegador do celular mudar de cor.

    Exemplo: <meta name="theme-color" content="#E9768E">

  • Color Scheme

    Indica uma sugestão de esquema de cor para que os navegadores ou demais interfaces usem para a página.

    Exemplos:

    <meta name="color-scheme" content="normal"> indica que não há conhecimento da existência de esquemas de cor, e que então deve ser utilizado o esquema padrão.

    <meta name="color-scheme" content="light"> indica que aquele documento suporta o esquema claro (se informado "dark", indica que suporta o esquema escuro). Caso constem dois nomes ("light dark"/"dark light"), indica que ambos os esquemas são suportados, mas que preferencialmente deve-se utilizar o primeiro.

    <meta name="color-scheme" content="only light"> indica que aquele documento suporta apenas o esquema claro. O "only dark" é inválido, pois forçar um equema escuro quando o navegar não o suporta pode ocasionar problemas de leitura do conteúdo (todos os maiores navegadores suportam o esquema claro).

  • Favicon

    Não é uma meta tag, mas sim um link. Isso pois não define informações sobre o documento, mas sim conecta ele a um arquivo.

    Define qual o ícone da página. É ele quem define o ícone que aparece nos sites favoritos/salvos no navegador.

    Exemplo: <link rel="icon" type="image/x-icon" href="icon.png">
