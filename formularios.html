Página inicial Meta tags Formulários

Tipos do elemento input

  • Color

    Cria um seletor de cores para que a pessoa escolha uma cor. O valor selecionado é fornecido, normalmente, no formato hexadecimal, como "#ff0000".

    Exemplo: <input type="color" name="cor-favorita" value="#9ECE6A"> inicia com um tom de verde-lima selecionado.

    Vendo na prática:

  • Date

    Cria um campo para selecionar uma data, sem horário. O navegador pode apresentar um calendário, e o valor é enviado no formato ano-mês-dia (AAAA-MM-DD).

    Exemplo: <input type="date" name="nascimento"> permite informar uma data de nascimento.

    Vendo na prática:

  • Datetime-local

    Cria um campo para selecionar uma data e um horário local. O valor segue o formato AAAA-MM-DDTHH:MM e não inclui informação de fuso horário.

    Exemplo: <input type="datetime-local" name="agendamento"> permite informar a data e o horário de um agendamento.

    Vendo na prática:

  • Email

    Cria um campo para informar um endereço de e-mail. O navegador pode verificar se o valor tem um formato válido, mas essa validação não confirma que o endereço existe nem substitui a validação no servidor.

    Exemplo: <input type="email" name="email" required> solicita um e-mail obrigatório (todo input que conter required é um campo de preenchimento obrigatório).

    Vendo na prática:

  • File

    Cria um campo para selecionar um ou mais arquivos do dispositivo. O atributo accept pode indicar os tipos de arquivo esperados, mas a verificação do arquivo também deve ser feita no servidor.

    Exemplo: <input type="file" name="documento" accept=".pdf"> permite selecionar um arquivo PDF.

    Vendo na prática:

  • Hidden

    Armazena um valor que é enviado com o formulário, mas não aparece como um campo editável na página. Como o valor pode ser visto e alterado por quem usa o navegador, ele não deve ser usado para guardar informações secretas nem ser considerado confiável.

    Exemplo: <input type="hidden" name="origem" value="pagina-inicial"> envia o valor "pagina-inicial" sem exibir um campo para a pessoa.

    Vendo na prática: (o campo existe, mas não aparece)

  • Image

    Cria um botão de envio de formulário apresentado como uma imagem. O atributo src indica a imagem e o atributo alt fornece um texto alternativo. Ao enviar, o navegador também pode incluir as coordenadas do clique.

    Exemplo: <input type="image" src="enviar.png" alt="Enviar formulário"> exibe uma imagem que envia o formulário quando acionada.

    Vendo na prática:

    Ao clicar na imagem, as coordenadas do clique vão para a URL. X e Y são zero no canto superior esquerdo.

  • Month

    Cria um campo para selecionar um mês e um ano, sem indicar um dia específico. O valor segue o formato AAAA-MM.

    Exemplo: <input type="month" name="validade"> permite informar um mês e um ano.

    Vendo na prática:

  • Number

    Cria um campo para inserir um número. Os atributos min, max e step podem definir valores mínimo, máximo e o intervalo permitido.

    Exemplo: <input type="number" name="quantidade" min="1" max="10" step="1"> aceita números inteiros de 1 a 10.

    Vendo na prática:

  • Range

    Cria um controle deslizante para escolher um valor numérico dentro de um intervalo. Os atributos min, max e step definem os limites e o intervalo dos valores.

    Exemplo: <input type="range" name="volume" min="0" max="100" value="50"> cria um controle de 0 a 100, iniciado em 50.

    Vendo na prática:

  • Search

    Cria um campo para inserir termos de pesquisa. Sua apresentação pode variar entre navegadores, e o envio ou a execução da pesquisa precisa ser implementado pela página.

    Exemplo: <input type="search" name="consulta" placeholder="Pesquisar"> cria um campo para digitar uma consulta.

    Vendo na prática:

  • Tel

    Cria um campo para informar um número de telefone. O navegador pode apresentar um teclado adequado em dispositivos móveis, mas não valida automaticamente um formato específico de telefone.

    Exemplo: <input type="tel" name="telefone" placeholder="(00) 00000-0000"> apresenta uma dica do formato esperado.

    Vendo na prática:

  • Time

    Cria um campo para selecionar um horário, sem data. O valor normalmente segue o formato HH:MM; o atributo step pode ajustar o intervalo, em segundos.

    Exemplo: <input type="time" name="hora" min="09:00" max="18:00"> limita o horário entre 9h e 18h.

    Vendo na prática:

  • Url

    Cria um campo para informar um endereço URL. O navegador pode verificar se o valor tem formato válido, mas isso não confirma se a página existe ou está acessível.

    Exemplo: <input type="url" name="site" placeholder="https://exemplo.com"> solicita um endereço de site.

    Vendo na prática:

  • Week

    Cria um campo para selecionar uma semana e um ano, sem indicar um dia específico. O valor segue o formato AAAA-WNN, em que NN identifica a semana (o W significa week, semana).

    Exemplo: <input type="week" name="semana"> permite informar uma semana do ano.

    Vendo na prática:

  • Outros atributos

    Atributos de formulário HTML

    action define o endereço que receberá os dados enviados. target define onde a resposta será aberta, como na aba atual ("_self") ou em uma nova aba ("_blank"). method define como os dados serão enviados: "get" os inclui na URL, enquanto "post" os envia no corpo da requisição. autocomplete habilita ou desabilita sugestões de preenchimento automático para os campos do formulário.

    Exemplo: <form action="/cadastro" target="_self" method="post" autocomplete="on">...</form>

    Atributos de entrada do formulário

    value define o valor inicial do campo. readonly impede que a pessoa altere o valor, mas ele continua sendo enviado. disabled desativa o campo, que não pode ser editado nem é enviado junto com o formulário.

    size define a largura visível de campos de texto, medida aproximadamente em caracteres. maxlength limita a quantidade máxima de caracteres digitados em campos compatíveis.

    min e max definem, respectivamente, os valores mínimo e máximo aceitos em tipos compatíveis, como "number" e "date". multiple permite vários valores em tipos compatíveis, como "email" e "file".

    placeholder exibe uma dica dentro do campo enquanto ele está vazio; não substitui um rótulo. required torna obrigatório o preenchimento do campo antes do envio. autofocus solicita que o campo receba o foco automaticamente ao abrir a página. autocomplete orienta o navegador sobre preencher um campo automaticamente, por exemplo, com "email" ou "off".

    Exemplo: <input type="text" name="cidade" value="São Paulo" readonly size="20"> apresenta um valor que não pode ser alterado e que será enviado.

    Vendo na prática:

    (não vai aparecer com foco pois é necessário clicar no details para que esse campo apareça nesta página)
